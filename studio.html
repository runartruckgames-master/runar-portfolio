Фотография профиля

Выбери фотографию. Она появится в предварительном просмотре и на этом устройстве.

Важно: это локальный редактор-черновик, а не защищённая админ-панель. Изменения сохраняются только в твоём браузере и отображаются в предпросмотре редактора, но не на публичном сайте. Чтобы фото увидели все посетители, скачай подготовленный JPG и загрузи его в папку assets репозитория под именем profile-photo.jpg. Затем опубликуй файл site-content.json. Не используй этот экран для хранения секретных данных.

Контакты

Описания проектов

Изменения видны только в предпросмотре. Названия и ссылки на исходные работы сохраняются.

Подготовка публикации

Мастерская хранит черновики только в этом браузере. Она не является защищённой панелью владельца. Публикация выполняется через GitHub с авторизацией на github.com.

Проверка готовности черновиков к публикации.

Скачать готовые тексты в файле site-content.json. Для появления изменений у посетителей этот файл нужно заменить в репозитории GitHub. Если публикуешь фото, сначала загрузи скачанный profile-photo.jpg в папку assets. Автоматической публикации и входа владельца пока нет.

Открыть файл на GitHub
Как опубликовать изменения
  1. Сохрани все нужные черновики и нажми "Скачать файл для сайта".
  2. Если менял фотографию, скачай JPG и загрузи его в папку assets на GitHub под именем profile-photo.jpg.
  3. Открой site-content.json по кнопке выше. Замени содержимое текстом из скачанного JSON-файла и сохрани коммит в main.
  4. Дождись публикации GitHub Pages и открой сайт посетителя. Черновики в браузере посетителям недоступны.

Никогда не вставляй GitHub-токены или пароли в эту страницу. Изменения на GitHub выполняются только после входа в свой аккаунт на github.com.

Резервная копия черновиков

Сохрани фотографию и тексты в один JSON-файл, чтобы перенести их в другой браузер или восстановить позже. Файл может содержать твою фотографию.

Проверка видеофайла

Выбери исходный MP4 или WebM на компьютере. Проверка выполняется локально, файл никуда не отправляется.

Публикация видео

После размещения файлов на хостинге сайта укажи их пути. Поддерживаются только MP4/WebM из папки assets/videos. Плееры появятся на сайте после публикации конфигурации.
