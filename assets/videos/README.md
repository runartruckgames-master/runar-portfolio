# Видео для портфолио

Разместите здесь MP4 (H.264/AAC) или WebM. В `video-sources.json` укажите соответствующие пути, например:

```json
{"version":1,"sources":{"tiny-workers":"assets/videos/tiny-workers.mp4","birthday":"assets/videos/birthday.mp4","magic-world":"assets/videos/magic-world.mp4"}}
```

До загрузки файлов публичный сайт показывает ссылки на Google Drive. Большие видео лучше размещать на специализированном видеохостинге или CDN, а не в Git-репозитории.
